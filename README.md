# 🎭 Zen-Zany

**Zen-Zany** is a simple and playful Random Advice Generator that delivers a mix of inspirational, thoughtful, and goofy advice messages. It’s designed to provide quick motivation, light humor, or a fresh perspective with a single tap.

🔗 **Live Demo:** https://zen-zany.vercel.app/  
📦 **Repository:** https://github.com/chinmay-260807/Zen-Zany.git

---

## ✨ Features

- 🎲 Random inspirational and goofy advice messages  
- 🧠 Lightweight and distraction-free experience  
- 🔄 Advice changes on refresh and button click  
- 📱 Fully responsive for mobile and desktop  
- ⚡ Fast and minimal interface  

---

## 🛠️ Tech Stack

- React  
- Vite  
- TypeScript  
- HTML, CSS, JavaScript  

---

## 🚀 How to Use the App (Tutorial)

1. Open the app using the live demo link above.  
2. When the page loads, a random advice message is displayed on the screen.  
3. Click the **“New Advice”** button to generate a fresh message.  
4. Refreshing the page will also show a different piece of advice.  
5. Use the app anytime you want motivation, humor, or a quick mental reset.

No login, setup, or configuration is required.

---

## 🧑‍💻 Run Locally

To run Zen-Zany on your local machine:

```bash
# Clone the repository
git clone https://github.com/chinmay-260807/Zen-Zany.git

# Move into the project folder
cd Zen-Zany

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173`.

---

## 📦 Build for Production

```bash
npm run build
npm run preview
```

This generates the optimized production build in the `dist/` folder.

---

## 🌐 Deployment

Zen-Zany is deployed using **Vercel**.

Recommended Vercel settings:
- Framework: Vite  
- Build Command: `npm run build`  
- Output Directory: `dist`
